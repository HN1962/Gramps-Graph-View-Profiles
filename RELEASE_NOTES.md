# Graph View Profiles V1.0

Initial public release.

## Added

- Standard profiles for reusable Graph View settings in one family tree.
- Named View profiles that can include the Home person and Active person.
- Startup choices for no profile, the Standard profile, or the current View profile.
- Temporary profile use with restoration of the settings active when the family tree was opened.
- One-time original settings backup created when the profile function is enabled for the first time.
- ProfileTag filtering from Configure and the Graph View right-click menu.
- A Profiles submenu in the Graph View right-click menu.
- Save, load, overwrite, and delete controls for Standard and View profiles.
- Validation of profile files, family-tree information, saved people, and supported settings before loading.
- Coordinated profile loading with one final Graph View rebuild.
- Support for saving zoom and chart position.
- Optional Danish translation supplied as `addon.mo`.

## Storage

- Standard profiles, startup settings, and restore files are stored in the shared `GraphView/profiles` folder.
- View profiles are stored in the base media folder of each family tree.
- No profile settings are added to `Gramps.ini`.

## Compatibility

- Gramps 6.0
- Graph View add-on
- Tested with Gramps 6.0.8 on Windows 11 and Zorin OS 18.1 Core
- macOS not tested
